This is a small python program to analyse Spotify streaming history data locally, with configurable options for processing :)


https://elleffnotelf.com



```
How to use:

    1. Get your streaming history from Spotify via https://www.spotify.com/us/account/privacy/, 
                    or by going to your account details -> "Account Privacy"
        Scroll down all the way to the bottom
        Check the checkbox for "Extended Streaming History" and uncheck "Account Data"
        Press the "Request Data" and return here when you receive the email with your data 
            Spotify states this takes up to 30 business days, anecdotally it's actually about 2-3, your mileage may vary.

    2. Download the program from here, along with your streaming data file from your email

    3. Place the program into a folder (with read and write permissions)

    4. Place the "my_streaming_data.zip" file into the "Data" folder inside the tool (don't unzip)
        You can customise the types of information you want to keep by using the config file (config.ini)

    5. Run the tool

    6. Wait for the data to be processed
```
