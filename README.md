###

A small tool to analyze Spotify streaming history data (locally)

https://elleffnotelf.com

```
How to use:
    1. Get your streaming history from Spotify via https://www.spotify.com/us/account/privacy/, 
                                    or by going to your account details -> "Account Privacy"
        Scroll down all the way to the bottom
        Check the checkbox for "Extended Streaming History" and uncheck "Account Data"
        Press the "Request Data" and return here when you receive the email with your data (1-30 business days, generally 2-3)
    2. Download the tool from here and your streaming data file from your email
    3. Place the tool into a folder (with read and write permissions)
    4. Place the "my_streaming_data.zip" file into the "Data" folder inside the tool
        You can open the main.py file and toggle the customisation options, if desired
        These dictate what information the tool will keep and display at the end
    5. Run the tool (for now, open main.py in an IDE and enter "python main.py" in the terminal)
    6. Wait for the data to be processed
```
